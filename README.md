# > Sobre este projeto: 🌟

Cibercriminosos utilizam diversos métodos para obter acesso não autorizado a aplicações. Um deles é o ataque de força bruta, no qual o invasor testa combinações de senhas consideradas "óbvias", como "senha123".

- Este projeto tem como finalidade gerar senhas seguras para usuários que desejam evitar credenciais vulneráveis. A ferramenta baseia-se em políticas de segurança nas quais o comprimento mínimo recomendado é de 8 caracteres, incluindo símbolos especiais, tornando a senha mais complexa e difícil de ser decifrada em um curto período de tempo.

---

# Características: 🔒

- O comprimento mínimo é de 8 caracteres, porém o usuário tem a liberdade de definir a quantidade que desejar. 

- É possível optar pela inclusão ou não de símbolos especiais. 

- O objetivo desta interface é exclusivamente auxiliar o usuário na criação de uma senha considerada forte.

---
- # 🔑 Gerador de Senhas Criptográficas

Este é um projeto desenvolvido com o objetivo principal de aplicar conceitos de segurança e criptografia utilizando **Python**. 

A lógica principal do aplicativo foi construída do zero em Python (utilizando a biblioteca padrão `secrets`), garantindo que as senhas geradas sejam criptograficamente seguras e imprevisíveis.

## 🛠️ Arquitetura do Projeto

* **Back-end:** Todo o desenvolvimento lógico, regras de segurança, manipulação de strings e geração de caracteres foram feitos em **Python**.
* **Front-end:** Utilizei **HTML/CSS** apenas como uma camada visual para tornar a interação do usuário mais intuitiva do que uma tela de terminal.
